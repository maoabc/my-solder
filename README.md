### 折腾原因
没有固定居住点，经常需要各种地方流动，焊台这些东西太重太占地方，所以需要一个便携式烙铁。市面上那些太贵还不能自己随意修改程序和硬件，不能自己迭代升级，还是自己从头搓的符合更符合自己流浪汉气质。
### 怎么制作
#### 硬件pcb部分
PCB基于立创eda绘制，可以下载hardware里面的文件导入立创eda，或者点击里面的开源硬件链接。t12的PCB包含主板部分和一个按键小板，这两个都需要。c210有两个版本，一个使用电阻分压的简单驱动，它驱动频率上不去（哪怕使用ciss低的aon7403都只敢到5kHz）加热时能听到轻微叫声，所以后面为了改进，使用mcp1415来驱动把pwm频率提升到20kHz，建议用新版本。PCB焊接建议先焊tps62933测试输出3.3v正常再焊接单片机和姿态传感器，这些焊好，再焊接周边阻容接口等等。
#### 外壳3d打印
模型基于openscad绘制的，scad这个目录就是源文件，可以进入通过右边releases下载生成好的模型，当然最推荐还是自己用openscad打开自定义后再生成属于自己的模型。t12和c210外壳都分两个部分，外壳主体和按键加顶部盖子的合体，需要打印这两个部分。c210底部金属头我闲鱼十块前包邮的，然后测量了尺寸给它建模，有需要可以按注释改.scad生成这些模型。
#### 刷机
硬件如果没问题了，接下来可以刷机。刷机时不能装烙铁头（这个很重要），按住k2然后插入usb线这时会进入dfu模式，然后使用STM32CubeProgrammer刷入固件。使用stlinker刷机，typec接口的sbu1和sbu2被连接到单片机的调试接口，可以用跟t12按键小板中额外附带的转接板把typec公头的sbu1和sbu2导出，这样就能连接到stlinker，然后也能通过烙铁的c口进行刷机调试。
